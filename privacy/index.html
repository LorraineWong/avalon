隐私政策

最后更新：2026 年 11 月 14 日。Avalon Online 是免费的非官方粉丝项目，不要求邮箱、真实姓名或注册玩家账号。

游戏运行所需的数据

网站使用 Firebase Anonymous Authentication 与 Realtime Database，处理随机生成的匿名 Firebase 用户 ID、玩家选择的昵称、房间成员与在线状态、公开游戏状态，以及多人游戏所需的加密身份和行动资料。

请只使用游戏昵称，不要把真实姓名、联系方式或其他敏感资料作为昵称或笔记内容。

保存在当前浏览器的资料

身份解密私钥、昵称、语言和主题偏好、上次房间号和私人推理笔记保存在当前浏览器的 localStorage。私人笔记不会上传 Firebase，也不会分享给房主或其他玩家；能使用同一设备与浏览器的人仍可能看到它们。

你可以在笔记面板中清空本局笔记，也可以通过浏览器设置删除本站的全部网站资料。

保存期限

新房间带有 72 小时有效期标记；已结束的游戏使用 24 小时标记。房主再次连接到过期房间时，房主客户端会删除房间资料。维护期间也可能删除旧资料；有效期不构成保证归档或准时删除的服务。

第三方服务与追踪

本站目前不包含广告追踪器，也不出售玩家资料。Firebase 与网页字体服务可能依据各自政策处理 IP 地址等必要网络资料。多人游戏仍需连接网络。

安全边界

身份与行动资料在浏览器中加密，但房主浏览器仍受信任并负责推进游戏。此设计能防止普通客户端和一般数据库查看，不防御已被入侵的房主浏览器或主动修改的客户端。请勿使用本服务处理敏感资料。

联系与报告

隐私或安全问题请通过 GitHub 仓库的 Security → Report a vulnerability 功能私密报告。不要在公开 Issue 中附上其他玩家的房间资料。

服务、存储与政策更新

Realtime Database 位于亚洲东南区（asia-southeast1）。字体由 Google Fonts（fonts.googleapis.com 与 fonts.gstatic.com）提供；服务商可能按其政策处理 IP 地址等必要服务资料。

应用代码不含分析统计或广告追踪，也不自行设置 Cookie。偏好和笔记使用 localStorage；Firebase 还可能使用浏览器存储保存登录状态。这不代表托管平台或第三方服务绝不使用 Cookie。

政策可能更新，变更以最后更新日期为准。私密安全报告请使用 GitHub Security。
