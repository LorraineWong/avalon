# Search favicon compatibility — 2026-11-18

Google reference: https://developers.google.com/search/docs/appearance/favicon-in-search

## Findings

The existing homepage declares a fixed 96px primary PNG, a 48px PNG, root ICO,
SVG fallback and 180px Apple touch icon. There is no `public/` directory in this
classified-source repository. `site/assets/` publishes as `/assets/` and
`site/meta/favicon.ico` publishes as `/favicon.ico` through `site-layout.mjs`.
The ICO is valid and contains 16, 32 and 48px images. No separate `shortcut icon`
is declared or required; `rel="icon"` is supported. No stale globe asset or broken
icon path was found. The right-hand search thumbnail is separate from the favicon.

## Change

Keep the existing 48px, 96px PNG, ICO, Apple touch and PWA images byte-for-byte.
Generate `site/assets/favicon-192.png` by downsampling the existing 512px
`brand-mark-dark.png` with Pillow LANCZOS. This retains the navy/gold artwork
and transparent corners, without redesign or a white matte.
Replace only the SVG favicon declaration with the new fixed 192px PNG declaration
in the homepage and twelve source content pages. Google currently lists PNG and
ICO among its supported search favicon formats, without listing SVG. This is a
compatibility improvement, not proof that the previous SVG declaration caused
the globe. The SVG asset remains available and unchanged.

The 37 canonical pages generated by preparation share the same raster icon set.
Existing favicon URLs have no query parameters and remain stable. The primary
96px address is unchanged. OG images, metadata, theme logos, all UI and Firebase
configuration are unchanged. Runtime assets and service worker are unchanged,
so the runtime remains v38; the new search icon is not added to the offline shell.

- Full offline suite: 24 tests and 17 syntax checks passed.
- Packaged 37 canonical pages validated for fixed 48/96/192px PNG references.
- Chrome decoded all three PNGs at their declared dimensions.
- Root ICO decoded with Pillow; existing Apple/PWA size checks passed.
- Public monitor now includes the new PNG (72 checks total), including exact
  bytes and PNG MIME type; page checks require all three PNG declarations.
- Publication must be verified at the merged SHA: Pages deployment and its

- After publication, GET the homepage, robots, all three PNGs, root ICO and
  Apple touch icon with normal, Googlebot and Googlebot-Image user agents;
  check HTTP 200, appropriate Content-Type and no X-Robots-Tag exclusion.
  User-agent simulations establish public access, not actual Google crawling.

## Search Console follow-up

Use URL Inspection for `https://playavalonnow.com/`, then Test live URL. Inspect
page availability, allowed indexing, Google-selected canonical and last crawl.
After the live test passes, request homepage indexing once. Do not submit the
PNG as an indexable page or resubmit the unchanged sitemap. Google says recrawl
and processing can take days to weeks and does not guarantee favicon display.
Only private Search Console evidence or verified Google crawler logs can confirm
actual Google crawling; neither is established by this repository change.
