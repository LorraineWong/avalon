# 公开网站巡检与日常查看

2026-11-16：站主授权将巡检、审计修正与房间分享改进一并发布为 v36。巡检是独立 Node24 脚本，不在玩家浏览器运行，不加载 Firebase SDK，不建立账号/房间，不采集玩家数据，也不使用登录凭据或付费服务。

## 自动检查

- **发布后**：`Publish static site` 的 `verify-public` 在 Pages deploy 成功后执行；检查失败不会自动回滚或再次部署。部署成功和发布后检查成功是两个独立结果。
- **每天**：`Daily public site check` 约在马来西亚时间08:17执行（UTC00:17），也可从 GitHub Actions 手动运行。只允许main执行，默认只读权限。
- 每次71项：37个公开页面、带语言/UTM的首页、robots/sitemap、三个开发页、20个关键资源、七个域名跳转和一个预期404。
- 页面检查HTTP状态、canonical、HTML语言、同类页面九语言hreflang/x-default、标题/描述与OG/Twitter一致性、分享图尺寸声明、图标声明、统一资源版本、首页基本JSON-LD及公共页面未误设noindex。
- 资源核对当前提交的精确内容摘要，包括首页脚本/九语言数据、主要样式、SW、logo、loading图、分享图、favicon/Apple/PWA图标与manifest。不会打印资源正文。
- 所有请求使用固定公开URL、GET、不发送凭据、不跟随跳转。旧域名仅核对301和目标路径/UTM，不访问个人站点。脚本没有递归抓取，不读取任何房间或身份API。
- 四个并发请求，每个请求15秒超时；同项最多三次，间隔5秒。持续失败时工作流失败并在日志/运行摘要列出出错URL与原因。正常时只显示简短通过结果。

进入 [Actions 巡检页面](https://github.com/LorraineWong/avalon/actions/workflows/public-site-check.yml) 查看结果。GitHub能否发送失败邮件取决于账号已有的Actions通知设置；本次没有修改个人设置、配置外部邮箱/聊天机器人或建立公开故障issue。可以在GitHub个人Settings → Notifications确认Actions失败通知偏好。不能把“任务已配置”说成“邮件投递已验证”。

GitHub定时任务可能延迟或漏调度；公开仓库长期无活动时定时任务也可能被暂停。它不是全天候可用性服务。脚本检测的是GitHub运行地点观察到的公开静态网站，不代表各国家网络可用、搜索已收录、真实手机分享卡正常或Firebase游戏可玩。前后端版本不匹配也可能来自部署/缓存传播，应先看部署结果和重试后的错误，勿关闭安全保护。

## 出错时

1. 打开失败运行，看具体URL、HTTP状态或内容差异；确认Pages本身是否成功，Workers构建单独看。
2. 浏览器正常时可手动重跑一次，区分短暂网络/边缘缓存与持续故障。
3. 持续问题通过PR修复；若发布破坏核心游戏流程，按[发布回滚规则](RELEASE.md)处理。不要因为静态巡检通过就断言多人整局通过。
4. 监控严格比较当前提交与网站资源，手动运行main之外的分支会被跳过；不要为通过检查而改成任意200即可。

## 每周SEO与推广期间查看

- Search Console：比较近28天与前28天的曝光、点击、CTR，按页面/设备/国家及搜索词拆分；数据不足时先积累，避免频繁改标题。站主已提交sitemap，无需每日重交。
- Search Console移动CWV：有真实数据后再看LCP/INP/CLS，数据缺失不等于不合格。固定条件的本地性能比较记录在[增长审计](GROWTH_AUDIT_2026-11-16.md)，不冒充真实用户指标。
- Firebase：推广期间查看RTDB连接、下载、存储及Auth/App Check相关异常；不把连接数当唯一玩家数，不自动改额度、Spark计费或安全配置。
- 分享：真实手机在常用聊天应用输入框粘贴邀请链接，确认卡片后可取消发送。统一图片与公开描述不含角色、昵称或房间状态；本轮自动巡检不打开社交账号。

## 本地检查

`node tests/run-all.mjs` 默认完全离线，包括模拟71项请求、临时故障重试恢复、持续失败、错误语言/noindex/跳转/资源等负向测试。

`node scripts/check-public-site.mjs` 才会读取真实公开网站，要求线上与当前checkout版本一致；可用环境变量 `PUBLIC_CHECK_REPORT` 指定本地JSON报告文件。不把该命令加进离线测试，也不把本机证据或临时报告发布到网站。
