# 中国大陆与全球访问分层报告

状态：Batch 0 准备稿，2026-11-15。**尚未证明大陆玩家可以完整联机。**
本报告目前只有依赖审计与执行机器的公开探测，不是 Batch 2 实网验收。

## 已知基线

- 当前正式站仍是 `avalon.lorrainewong.dev`，GitHub Pages v29；134 个公开发布文件
  与产物一致。执行机器正常 TLS 请求首页为 200；执行机器出口地区未验证。
- 新 `playavalonnow.com` 已委派 Cloudflare NS，但权威 A/AAAA 为空，www 为
  NXDOMAIN，目前还没有新站可测。此状态不能归因于大陆网络。
- Firebase compat SDK 和二维码脚本本地托管；13 个 HTML 源文件仍引用 Google Fonts。
- 身份、reCAPTCHA/App Check、数据库连接依赖外部 Google 服务；数据库在
  `asia-southeast1`，不等于大陆连接已被验证。
- 负责人曾提及过去的多节点 HTTP 测试；本轮未取得原始记录，不重建或虚构成功率。
- 本轮没有对真实 Firebase 用户/房间进行测试，没有压力测试。

## 分层验收与错误记录

| 层 | 实际动作 | 成功证据 | 重点故障域名/类型 |
| --- | --- | --- | --- |
| L1 | 本机与公共 DNS 查询正式主机 | 答案/解析器/耗时，不能只记录域名购买成功 | 正式域名、递归 DNS |
| L2 | 正常 TLS 打开首页及必要 CSS/JS/图 | 证书、状态码、耗时、失败资源；允许区分非必要字体失败 | 正式域名；fonts.googleapis.com / fonts.gstatic.com |
| L3 | 浏览器初始化页面、昵称和按钮可用 | 可见状态与页面错误 | 本地托管 SDK、游戏 JS |
| L4 | 临时客户端匿名登录与令牌续期 | 状态码、阶段、耗时，不保存 token/uid | identitytoolkit.googleapis.com / securetoken.googleapis.com |
| L5 | 真实 reCAPTCHA/App Check token | 交换状态与耗时；“Registered”不够 | www.google.com/recaptcha、www.gstatic.com/recaptcha、firebaseappcheck.googleapis.com；以当次网络请求为准 |
| L6 | 同一临时房间的读写、连接和重连 | 有权限同步、越权拒绝、连接类型与延迟 | firebasedatabase.app 实例及实际 WebSocket/长轮询主机 |
| L7 | 独立身份多人完成提名/投票/Quest/胜负 | 设备、网络、人数、流程、恢复与清理记录 | 端到端游戏同步，不用 HTTP 200 替代 |

每个测试行追加：时间（含时区）、城市/运营商/宽带或手机、工具/浏览器、版本、
层级、重复次数/通过次数、失败阶段、域名和错误类别、恢复方法。
不把完整 room code、角色/投票、token、昵称、私密日志或精确 IP 放进公开报告。

## 优化顺序与停止条件

1. Batch 1 验收完成后，在真实新域名采集分层结果和海外对照。
2. 先减少非必要字体外网依赖，评估系统字体/合法本地字体的体积、九语言字形与
   排版；保持 UI 风格，不为测试随意禁用生产安全脚本。
3. 弱网限速/断网模拟用于可理解错误、15 秒等待反馈、重连和重复操作测试，
   单独标为模拟。现有通用 `noNet` 提示还不能区分所有鉴权/房间错误。
4. 若 L4/L5/L6 在实网失败，记录实际服务与错误，不假定更换静态 CDN 能解决。
   不关 App Check、不公开数据库、不使用开放代理、不导出服务账号。
5. 替代后端/身份方案只做评估表，比较代码改动、独立后端、免费额度、全球影响、
   安全模型、维护、可能合规要求和回滚；未经负责人批准不迁移。

当前没有足够证据选择后端迁移，也不能承诺中国大陆全面可用。
